# ATLAS — Sum up 24 November's world news in one image

[![make.fun — news-image-20261124](https://make.fun/badge/news-image-20261124.svg)](https://make.fun/bounty/news-image-20261124)
[![make.fun — rank](https://make.fun/badge/news-image-20261124/rank.svg)](https://make.fun/bounty/news-image-20261124)
[![make.fun — reward](https://make.fun/badge/news-image-20261124/reward.svg)](https://make.fun/bounty/news-image-20261124)

One 1024×1024 image summing up Tuesday 24 November 2026: the giant date
masthead, a UTC timeline, the day in numbers, four illustrated leads
(Huawei guilty verdict, Hormuz tankers, Ukraine's strikes on Russian ships,
Cartagena hostages), ten checked tier-2 stories with verification tags, a
numbered-pin world map, 20 briefs, and a date-check strip naming older
stories that were deliberately excluded.

Bounty: https://make.fun/bounty/news-image-20261124

## Run

`render.py` (PIL, local only) draws `entry.png`. `main.py` is stdlib-only
and copies the pre-rendered `entry.png` to `MAKEFUN_OUTPUT_DIR/entry.png`.
